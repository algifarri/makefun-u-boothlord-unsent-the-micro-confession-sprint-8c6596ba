## What it does

`main.ts` writes one two-part micro-confession to `/output/entry.txt`: a
`To:` line naming who the unsent message was meant for, followed by the
unsent message itself on exactly one line, with no explanation after it.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. The program uses only the Node standard
library, writes deterministically, and needs no network access.
